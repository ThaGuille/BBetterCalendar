# u1 - emulator probe, profile and fail-fast

Probe command: `python .claude/scripts/emulator-probe.py --count 2`

Output against the two running emulators (exit 0):

```
emulator-probe: emulator-5554 ready
emulator-probe: emulator-5556 ready
```

Decision on the grace: `with-emulator.py --none-grace-s` defaults to 60 s. When adb lists no emulator-* at all it waits
that long for one to appear, then prints `with-emulator: no emulator attached` and exits 3. With emulators attached but
all leased the old wait (`--timeout-min`, 20 min) is unchanged. If an emulator appears, the grace restarts should all
vanish later. The profile lists that message as a signature, so bt treats it as an environment failure (and runs
`ready`) instead of a unit failure.
