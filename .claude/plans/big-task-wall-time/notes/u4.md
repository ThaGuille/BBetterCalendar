# u4 - install once per commit (with-emulator.py --install)

- `with-emulator.py --install` runs `gradlew.bat|./gradlew installDebug` (checkout of the script, ANDROID_SERIAL set) before the command; a failed install exits with Gradle's code and skips the command.
- Record `<leases dir>/<serial>.installed` = `HEAD lastUpdateTime` (written only on a clean tracked tree). Skip when both still match. Dirty tracked tree: always installs, no record. Never read as a lease (only `*.lock` are).
- Install lines go to stdout (bt run-check reads stdout then stderr; the check wants "skipped" before the command's output).
- Test-only switches: `--assume-clean`, `--install-cmd`, `--head`, `--dirty`, `--update-time-file`.
- Measured on emulator-5556 (warm Gradle, already built): `--install` skipped = 2 s for the whole check; forced install (record deleted) = 8 s for the whole check.
