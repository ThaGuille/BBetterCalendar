# u8 - adb-ui-test skill: ASSERT alternation and START force-stop

Two decisions documented in `.claude/skills/adb-ui-test/SKILL.md` (Replay defaults section):

- F4: the ASSERT `expect~=` grammar is a case-insensitive substring match with `a|b` alternation, so a recording survives the
  emulator language. A literal `|` in an expected text is therefore an alternation separator. Kept as is because the AVD runs
  in English.
- F2: every START (replay, record, run-steps) force-stops the app first, so a mid-walk START loses in-memory state. To relaunch
  with extras, keep the app state in the database or start a separate walk.
