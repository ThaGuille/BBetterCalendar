# u9 - seed script deletes "Reunion" only on emulators (review F3)

- Decision: the delete of `projectId = 0 AND title = 'Reunion'` events is kept, because the mv-tour walk adds one per run and the walk is only repeatable if the seed removes them. It is limited to emulators: `clear_seeded(c, packages, delete_reunion=False)` is off by default, `device_run` turns it on only when the serial starts with `emulator-`, and local (`--db`) mode never sets it. A real user's "Reunion" events on a phone survive.
- Test: `.claude/scripts/test/test_seed_progress_db.py` (in-memory sqlite, no device).
